# LaneTheory

Локальный игровой overlay для Dota 2. Он получает разрешённые данные через Game State Integration, показывает рекомендации по линии и драфту, таймеры и ситуативные предметы поверх игры.

## Драфт-анализ

![Ручной draft picker, ranked counter picks и situational items](docs/screenshots/draft-analysis.png)

## Что уже есть

- Автоматическое создание GSI-конфига при первом запуске.
- Рекомендации по роли, рейтинговому диапазону и доступной статистике OpenDota.
- Анализ ручного драфта: counter picks, вклад каждого match-up, покрытие пиков и ситуативные предметы.
- Одноразовый Vision-скан драфта по F10 с возможностью поправить результаты вручную.
- Трекер Roshan и кулдаунов ключевых ультимейтов с выбором уровня ультимейта.
- Советы по Magic Stick / Magic Wand и событиям карты без повторов TTS.
- Горячие клавиши для role, focus mode, полного скрытия, настроек, Roshan и Vision.

## Управление

| Клавиша | Действие |
| --- | --- |
| F5 | Сменить роль |
| F6 | Оставить только важные уведомления |
| F7 | Скрыть или вернуть весь overlay |
| F8 | Настройки и интерактивные элементы |
| F9 | Таймер Roshan и сторона убийства |
| F10 | Одноразово распознать пики на экране драфта |

## Запуск

1. Установить Dota 2 и запустить `run.bat`.
2. Первый запуск создаст `gamestate_integration_lanetheory.cfg` в каталоге Dota 2. Если игра уже открыта, полностью перезапустить её.
3. Для свежей статистики OpenDota нужен доступ к API. При недоступности сети overlay продолжает работать с локальным bootstrap-кэшем.

`-gameintegration` в параметрах запуска не требуется: конфиг GSI подключается самой Dota 2.

## Данные и обновления

В репозитории лежит минимальный bootstrap-набор героев, предметов и hero stats, который вшивается в бинарник. При запуске предметы обновляются из OpenDota с ограниченным таймаутом; недоступность API не останавливает приложение.

Новый формат офлайн-пакета `.ypk` и его reader будут добавлены отдельным изменением. Формат не будет привязан к номеру версии клиента: пакет будет содержать manifest, снимок источников, версию схемы и контрольные суммы.

## Ограничения

- GSI не отдаёт пики соперника на стадии драфта. Для этого есть ручной picker и F10 Vision scan.
- Vision предназначен как быстрый ввод, а не как источник безошибочных данных: результаты нужно сверять и при необходимости корректировать в picker.
- Статистика зависит от доступности публичных источников и их текущего патча.

## Разработка

```powershell
$env:CARGO_BUILD_JOBS=6
cargo build --release
```

GitHub Actions собирает Windows-артефакт для каждого изменения в `main` и для тегов релиза.
